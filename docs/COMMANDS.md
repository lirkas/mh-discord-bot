## Discord bot Commands

```yaml
    !cmds                           : Display all the available commands
    !help           COMMAND         : Display help for a specific command
    !hitzonefu|hfu  MONSTER         : [MHFU] Display hitzone values for a specific monster
    !itemf1|if1     ITEM            : [MHF1] Find the possible ways to obtain an item
    !itemfu|ifu     ITEM            : [MHFU] Find the possible ways to obtain an item
    !itemp3|ip3     ITEM            : [MHP3] Find the possible ways to obtain an item
    !itemxx|ixx     ITEM            : [MHXX] Find the possible ways to obtain an item
    !monsterf1|mf1  MONSTER RANK    : [MHF1] Display obtainable items from a specific monster
    !monsterfu|mfu  MONSTER RANK    : [MHFU] Display obtainable items from a specific monster
    !monsterp3|mp3  MONSTER RANK    : [MHP3] Display obtainable items from a specific monster
    !monsterxx|mxx  MONSTER RANK    : [MHXX] Display obtainable items from a specific monster
    !reload|rdata   GAME            : [ADMIN] Reload monster data
```

`MONSTER` and `ITEM` can be names or IDs.<br>
IDs refer to the ones shown by the bot, not in-game internal IDs.
